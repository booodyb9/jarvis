# نتائج تطوير دردشة مساعدك والفقاعة

التنفيذ المعتمد محفوظ في PR #4:
https://github.com/booodyb9/jarvis/pull/4

## ما تغيّر
- الرئيسية أصبحت دردشة عربية حقيقية، والفقاعة تشاركها نفس السجل والمسودة.
- صوت عند الطلب مع مراجعة النص، ورد مكتوب وقراءة صوتية من أول ضغطة، وتقسيم الردود الطويلة حسب حد Android.
- وضع دردشة منفصل عن وضع الشاشة، مع الحفاظ على الموافقات الأصلية لكل فعل.
- صفحة إعدادات مستقلة للمزود والنموذج والمفتاح واختيار الأساسي واختبار الدردشة والأدوات كل على حدة.
- تصميم مضغوط عند نقص الارتفاع، ومراجعة نص الفعل الطويل بالتمرير دون إخفاء زري الموافقة.
- «محادثة جديدة» تلغي الطلبات والموافقات القديمة؛ دوران الخدمة لا يلغي دردشة عادية.

صور الواجهة المولّدة للرئيسية والفقاعة والموافقة تمت مراجعتها.
